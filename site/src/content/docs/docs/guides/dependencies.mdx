## What it is

wdx is one binary, but some of what it does runs other programs: git always, and optionally a clipboard tool, a container runtime, GitHub's `gh`, terminal editors and the AI CLIs themselves. `wdx deps list` says which are ready and what each one enables, and `wdx deps install` installs one with your system's package manager.

## Try it

```console
$ wdx deps list
git           mandatory  ready  git 2.53.0     projects, terminals
clipboard     optional   ready  wl-copy        tide copy
container     optional   ready  docker 29.9.3  observe
gh            optional   ready  gh 2.46.0      landing by PR
vi            optional   ready  vi             tide edit
vim           optional   ready  vim            tide edit
nvim          optional   ready  nvim           tide edit
nano          optional   ready  nano           tide edit
hx            optional   ready  hx             tide edit
emacs         optional   ready  emacs          tide edit
claude        optional   ready  claude         agents: claude_code
agy           optional   ready  agy            agents: antigravity
cursor-agent  optional   ready  cursor-agent   agents: cursor
codex         optional   ready  codex          agents: codex
system: ubuntu, installs with apt, wayland session
```

Install one that is missing:

```sh
wdx deps install --name gh
```

## How it behaves

- **States.** `ready`; `missing`; `too_old` (git before 2.31); or `not_ready`, installed but not usable, as docker whose daemon does not answer, with why below the table.
- **What each enables.** git is needed for anything. The clipboard tool lets TIDE copy (`wl-copy` on Wayland, `xclip` or `xsel` on X11, `pbcopy` on macOS); docker or podman runs [Observability](/wdx/docs/guides/observability/); `gh` lands worktrees by PR; an editor edits files in TIDE (the `editor` setting picks one); each AI CLI lets agents run it.
- **Installing** uses apt on Ubuntu and Debian and brew on macOS. When that needs root, the commands are shown and you are asked before `sudo` runs them; `--yes` answers in advance. A dependency already ready is left as it is, and every failure says how to install it yourself.
- **AI CLIs** are installed their own way, as each one's docs say; `deps list` shows whether wdx finds them. `wdx agent acas` lists those agents can run.
- **Found as your login shell finds them,** since agents run through it: a program on your `PATH` in a terminal is found.
